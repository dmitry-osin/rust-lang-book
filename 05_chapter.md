### Глава 5. Составные типы данных

В Rust есть четыре основных способа группировать данные. Мы пойдем от простых к самым мощным.

#### 1. Кортежи (Tuples): Быстрая связка разнородных данных

**Кортеж** — это как небольшая коробка, в которую мы можем положить несколько предметов **разного типа**. Главное правило: размер кортежа фиксируется при создании, мы не можем потом добавить туда новые элементы.

Кортежи создаются с помощью круглых скобок `()`.

```rust
fn main() {
    // Создаем кортеж с тремя элементами: строка, целое число, дробное число
    let person_info = ("Дмитрий", 30, 75.5);

    // Как достать значения? 
    // Способ 1: Прямой доступ по индексу (через точку). Нумерация начинается с нуля!
    println!("Имя: {}", person_info.0);
    println!("Возраст: {}", person_info.1);

    // Способ 2: Деструктуризация (распаковка). Очень частый и красивый прием.
    // Мы сразу "разбираем" кортеж на отдельные переменные.
    let (name, age, weight) = person_info;
    println!("Вес {}: {}", name, weight);
}
```

*Где это применяется?* Кортежи идеальны, когда функции нужно вернуть не один результат, а сразу два или три (например, результат вычисления и статус успеха), а создавать ради этого полноценную структуру не хочется.

#### 2. Массивы (Arrays): Строгий ряд одинаковых элементов

**Массив** — это длинная полка, на которой стоят предметы **только одного типа**. Как и у кортежей, длина массива фиксирована и не может меняться (для динамических списков мы будем использовать `Векторы` в будущих главах).

Массивы создаются с помощью квадратных скобок `[]`.

```rust
fn main() {
    // Массив из 5 целых чисел
    let numbers = [10, 20, 30, 40, 50];
    
    // Доступ по индексу (в квадратных скобках)
    println!("Первое число: {}", numbers[0]); // 10
    println!("Третье число: {}", numbers[2]); // 30

    // Массив из 7 одинаковых значений (например, дни недели, заполненные нулями)
    // Синтаксис: [значение; количество]
    let zeros = [0; 7]; // Создаст [0, 0, 0, 0, 0, 0, 0]
}
```

**Безопасность Rust:** Что будет, если в `numbers` всего 5 элементов (индексы от 0 до 4), а мы попробуем прочитать `numbers[10]`? В C/C++ программа молча прочитала бы чужой кусок памяти, что привело бы к уязвимости. Rust же немедленно остановит программу (произойдет паника `panic!`) с сообщением: *"индекс вышел за пределы массива"*.

#### 3. Структуры (Structs): Именованные данные

Кортежи удобны, но когда данных много, легко запутаться: что такое `person.0`, а что `person.3`? 
**Структура** — это тот же кортеж, но в котором у каждого поля есть понятное имя (ключ) и жестко заданный тип.

Структуры определяются с помощью ключевого слова `struct`.

```rust
// Определение структуры (чертеж)
struct User {
    username: String,
    email: String,
    sign_in_count: u64,
    active: bool,
}

fn main() {
    // Создание экземпляра структуры (реальный объект по чертежу)
    let mut user1 = User {
        email: String::from("test@example.com"),
        username: String::from("AktiveHateX"),
        active: true,
        sign_in_count: 1,
    }; // Порядок полей при создании не обязан совпадать с чертежом

    // Доступ к полям через точку
    println!("Добро пожаловать, {}!", user1.username);

    // Изменение поля (возможно только если структура создана как mut)
    user1.sign_in_count = 2;
}
```

**Структуры-кортежи (Tuple Structs):**
Иногда нам нужно дать имя самому типу данных, но при этом имена полей нам не важны.
```rust
struct Color(i32, i32, i32); // RGB цвета
struct Point(i32, i32, i32); // Координаты X, Y, Z

let black = Color(0, 0, 0);
let origin = Point(0, 0, 0);
// black и origin имеют разный тип, их нельзя случайно перепутать или сложить, 
// хотя внутри у обоих просто три числа.
```

#### 4. Перечисления (Enums): Типы с вариантами

Здесь начинается магия. В большинстве языков перечисления — это просто список именованных чисел (например, Красный = 0, Желтый = 1, Зеленый = 2). 
В Rust **`enum` (перечисление)** — это невероятно мощная конструкция. Оно позволяет сказать: «Значение может быть либо ЭТИМ, либо ТЕМ».

```rust
// Простое перечисление (как в других языках)
enum TrafficLight {
    Red,
    Yellow,
    Green,
}
```

Но в Rust каждый вариант перечисления **может хранить внутри себя данные**, причем разных типов!



```rust
// Сложное перечисление
enum WebEvent {
    PageLoad,                  // Вариант без данных
    KeyPress(char),            // Вариант хранит один символ (структура-кортеж)
    Paste(String),             // Вариант хранит строку
    Click { x: i64, y: i64 },  // Вариант хранит полноценную структуру!
}

fn main() {
    // Мы можем создать любую из этих "сущностей", и все они будут одного типа WebEvent
    let event1 = WebEvent::KeyPress('q');
    let event2 = WebEvent::Click { x: 250, y: 140 };
}
```
*Почему это круто?* Это позволяет создавать функции, которые принимают `WebEvent`, и компилятор будет абсолютно уверен, что мы передали правильное событие со всеми необходимыми данными внутри него. 

#### 5. Тип Option: Как Rust победил "Ошибку на миллиард долларов"

Создатель концепции `null` (пустоты) в программировании назвал ее своей "ошибкой на миллиард долларов", потому что попытка обратиться к переменной, которая оказалась `null`, приводит к падению программ (знаменитый `NullPointerException` в Java).

В Rust **нет `null`**. Вообще. 

Как тогда сказать, что "значения может не быть"? (Например, функция поиска не нашла пользователя).
Для этого Rust использует встроенное перечисление **`Option`** (Опция / Вариант).

Оно определено в стандартной библиотеке примерно так:
```rust
enum Option<T> { // <T> означает "любой тип данных"
    Some(T), // Есть значение типа T (перечисление с данными)
    None,    // Ничего нет (пустота)
}
```

Представь, что `Option` — это подарочная коробка. Она может быть либо `Some` (внутри лежит подарок, например число или строка), либо `None` (коробка пуста).

```rust
fn main() {
    let some_number = Some(5);          // Тип Option<i32>
    let some_string = Some("Привет");   // Тип Option<&str>
    
    // Если мы хотим создать пустоту, мы должны явно указать тип, 
    // чтобы компилятор знал, коробку КАКОГО типа мы оставляем пустой
    let absent_number: Option<i32> = None; 
    
    // let result = 5 + some_number; 
    // ОШИБКА! Компилятор не даст тебе сложить обычное число (5) и Option.
    // Почему? Потому что some_number — это КОРОБКА. 
    // Чтобы сложить числа, ты должен сначала безопасно достать значение из Some.
}
```

Именно то, что компилятор *заставляет* тебя проверять коробку перед тем, как достать из нее данные, делает падения из-за отсутствующих данных в Rust практически невозможными!

---

**Резюме:**
*   **Кортежи `()`**: Разные типы, без имен, доступ по индексу.
*   **Массивы `[]`**: Одинаковые типы, фиксированная длина, доступ по индексу.
*   **Структуры `struct`**: Разные типы, с именами полей.
*   **Перечисления `enum`**: Значение может быть одним из нескольких вариантов, и каждый вариант может нести свои данные.
*   **`Option`**: Изящная замена `null`. Значение либо `Some(данные)`, либо `None`.
