### Глава 3. Азбука программирования

В этой главе мы познакомимся с кирпичиками, из которых строится любая программа. Мы научимся хранить данные, выполнять вычисления и заставлять программу принимать решения.

#### 1. Переменные: Коробки для данных и Неизменяемость

Представь, что оперативная память компьютера — это огромный склад. Чтобы не потерять свои вещи (данные), мы кладем их в подписанные коробки. Эти коробки называются **переменными**.

В большинстве языков программирования ты можешь положить что-то в коробку, а потом в любой момент достать это и положить что-то другое. Но Rust мыслит иначе. 

По умолчанию все переменные в Rust **неизменяемые (immutable)**. Представь, что как только ты положил значение в коробку, компилятор намертво заклеивает её скотчем.

```rust
fn main() {
    let speed = 100; // Создаем коробку с именем speed и кладем туда 100
    
    // speed = 120; // ОШИБКА! Компилятор ударит по рукам: "Нельзя менять заклеенную коробку!"
    println!("Текущая скорость: {}", speed);
}
```
*Примечание: `{}` внутри текста для `println!` — это специальное "пустое место" (плейсхолдер), куда подставится значение нашей переменной.*

**Зачем Rust всё усложняет?** 
Ради твоей безопасности! В больших программах, когда данные могут меняться из разных мест одновременно, происходят самые трудноуловимые ошибки (баги). Если переменная неизменяемая, ты всегда уверен на 100%, что никто и никогда её не испортит.

Но программы должны меняться! Если тебе *действительно* нужно изменять значение, ты должен прямо сказать об этом компилятору с помощью волшебного слова **`mut`** (от слова mutable - изменяемый). Это как коробка с открытой крышкой.

```rust
fn main() {
    let mut score = 0; // Теперь это изменяемая коробка
    println!("Счет в начале: {}", score); // Выведет 0

    score = 10; // Всё легально, мы разрешили изменения!
    println!("Новый счет: {}", score); // Выведет 10
}
```

#### 2. Типы данных: Что лежит в коробке?

Rust — язык со строгой типизацией. Компилятор всегда должен знать, *что именно* лежит в коробке: число, текст или что-то еще. Часто Rust сам догадывается о типе (это называется *вывод типов*), как в примерах выше. Но иногда нам нужно указать тип явно.

Базовые (скалярные) типы в Rust делятся на четыре группы:

1.  **Целые числа (Integers):** Числа без дробной части.
    Бывают со знаком (могут быть отрицательными) — обозначаются буквой `i` (от *integer*). И без знака (только ноль и положительные) — буква `u` (от *unsigned*).
    Рядом с буквой пишется размер коробки в битах (8, 16, 32, 64, 128). Чем больше бит, тем большее число влезет.
    *   `i32` — стандартный тип по умолчанию. Вмещает числа примерно от -2 миллиардов до +2 миллиардов. (Как баланс на банковском счете).
    *   `u8` — вмещает только от 0 до 255. (Идеально для возраста человека).
    ```rust
    let age: u8 = 25; // Явно указываем, что коробка age типа u8
    ```

2.  **Числа с плавающей точкой (Floats):** Дробные числа.
    Обозначаются буквой `f`. Бывают `f32` и `f64`. По умолчанию используется `f64`, так как на современных компьютерах он работает так же быстро, но точнее.
    
```rust
    let weight: f64 = 75.5;
    ```

3.  **Логический тип (Boolean):** Хранит только два состояния: `true` (истина) или `false` (ложь). Как выключатель света.
    ```rust
    let is_raining: bool = false;
    ```

4.  **Символ (Char):** Одиночный символ в одинарных кавычках. В Rust он может хранить любую букву, даже иероглиф или эмодзи!
    ```rust
    let letter = 'A';
    let heart = '❤';
    ```

**Преобразование типов (Кастинг):**
В отличие от многих языков, Rust никогда не будет пытаться "втихаря" сложить дробное число с целым. Если типы разные, компилятор выдаст ошибку. Тебе нужно явно переделать один тип в другой с помощью ключевого слова **`as`**.

```rust
let apples = 5; // тип i32
let price_per_apple = 2.5; // тип f64

// let total = apples * price_per_apple; // ОШИБКА: разные типы!
let total = (apples as f64) * price_per_apple; // Делаем из apples временную копию типа f64
```

#### 3. Арифметические и поразрядные операции

Здесь всё как в обычной математике:
*   Сложение `+`, Вычитание `-`, Умножение `*`, Деление `/`.
*   Остаток от деления `%` (например, `10 % 3` вернет `1`, потому что 10 делится на 3 с остатком 1).

**Поразрядные операции** — это продвинутая математика. Они позволяют напрямую манипулировать битами (нулями и единицами) внутри чисел: `&` (И), `|` (ИЛИ), `^` (Исключающее ИЛИ), `<<` (Сдвиг влево). 
Как новичку, они тебе понадобятся очень нескоро (обычно их используют при программировании микроконтроллеров или в сложных алгоритмах шифрования). Поэтому пока просто помни, что они есть.

#### 4. Ветвления: Учим программу принимать решения



Самый главный инструмент логики — конструкция **`if..else`** (если..иначе).

```rust
let temperature = 15;

if temperature > 25 {
    println!("Жарко, надевай футболку.");
} else if temperature > 10 {
    println!("Прохладно, надень легкую куртку.");
} else {
    println!("Холодно, бери пуховик!");
}
```

**Киллер-фича Rust:** В Rust `if` — это не просто инструкция, это *выражение*. Это значит, что сам блок `if` может возвращать значение, которое можно сразу положить в переменную!

```rust
let is_weekend = true;

// Мы сразу кладем результат работы if в переменную action
let action = if is_weekend {
    "Спать до обеда"
} else {
    "Идти на работу"
}; 
// Обрати внимание: внутри { } нет точек с запятой, потому что мы ВОЗВРАЩАЕМ это значение
// А вот после закрывающей скобки всего if мы ставим точку с запятой, так как закончили инструкцию let

println!("Сегодня я буду: {}", action);
```

#### 5. Циклы: Как заставить код повторяться

Иногда нужно сделать одно и то же действие много раз. В Rust для этого есть три вида циклов (беговых дорожек).

**1. Бесконечный цикл `loop`:**
Программа будет выполнять код внутри бесконечно, пока ты её принудительно не остановишь (или пока она не встретит внутри команду **`break`** - "выйти из цикла").

```rust
let mut counter = 0;
loop {
    counter += 1; // Это то же самое, что counter = counter + 1
    println!("Круг номер: {}", counter);

    if counter == 3 {
        println!("Хватит с меня!");
        break; // Экстренный выход из цикла
    }
}
```

**2. Цикл с условием `while` (пока):**
Выполняется до тех пор, пока условие является истиной (`true`).

```rust
let mut battery = 3;

while battery > 0 {
    println!("Телефон работает. Заряд: {}", battery);
    battery -= 1;
}
println!("Телефон выключился.");
```

**3. Цикл `for` (для):**
Самый безопасный и популярный цикл в Rust. Он используется, когда мы точно знаем, сколько раз хотим выполнить код, или когда перебираем список элементов.
Чтобы выполнить код определенное количество раз, мы используем **Range (Диапазон)**: `начало..конец` (не включая конец) или `начало..=конец` (включая конец).

```rust
// Выведет числа 1, 2, 3, 4, 5
for number in 1..=5 {
    println!("Число: {}", number);
}
```
*Почему `for` лучший?* В нем невозможно случайно застрять навечно или ошибиться с счетчиком (как это бывает в других языках). Компилятор сам позаботится о том, чтобы пройтись от первого элемента до последнего и остановиться.
