### Глава 1. Введение в мир Rust

Добро пожаловать в Rust! Это язык, который программисты по всему миру называют самым любимым уже много лет подряд. И на это есть веские причины. 

#### Общий обзор языка: почему Rust такой быстрый и безопасный?

В мире программирования долгое время существовала дилемма, похожая на выбор автомобиля:
1.  **Языки без автоматической уборки памяти (C, C++)** — это гоночные болиды. Они невероятно быстрые, потому что программист управляет всем сам. Но в них нет подушек безопасности. Если ты ошибся и попытался залезть в память, которой не существует (все равно что попытаться открыть несуществующую дверь на скорости 200 км/ч), программа просто «падает» (происходит краш).
2.  **Языки со сборщиком мусора (Python, JavaScript, C#)** — это комфортные бронированные внедорожники. Они очень безопасные. За тобой постоянно ездит специальная программа (сборщик мусора), которая следит за тем, что ты делаешь, и убирает за тобой старые данные. Но из-за этого внедорожник получается тяжелым и медленным.

**Rust — это попытка создать гоночный болид с идеальным автопилотом безопасности.** 
Он такой же быстрый, как C и C++, потому что в нем нет «сборщика мусора», который тормозит программу. Но при этом в нем практически невозможно допустить критическую ошибку с памятью. 

Как это работает? В Rust есть **очень строгий компилятор** (программа, которая переводит твой код в нули и единицы для компьютера). Компилятор Rust выступает в роли дотошного инспектора. Он проверяет твой код *до* того, как программа будет запущена. Если инспектор видит, что твой код может привести к аварии (например, две части программы пытаются одновременно изменить одни и те же данные), он просто **откажется собирать программу** и выдаст ошибку с подробным объяснением, как ее исправить.

Сначала этот компилятор будет казаться тебе строгим учителем, но очень скоро ты поймешь, что он твой лучший друг. Если программа на Rust скомпилировалась — скорее всего, она будет работать без сюрпризов.

#### Установка Rust и настройка окружения

Чтобы начать писать программы, нам нужно установить сам язык. В мире Rust всё стандартизировано, и для установки используется специальная программа, которая называется **`rustup`**. Она устанавливает сам язык, компилятор и все необходимые инструменты.

**Как установить:**
Тебе нужно открыть командную строку (Терминал) на твоем компьютере.
*   **Если у тебя Windows:** Проще всего зайти на официальный сайт [rust-lang.org](https://www.rust-lang.org/tools/install) и скачать файл `rustup-init.exe`. Просто запусти его и следуй инструкциям на экране (можно везде нажимать Enter для стандартной установки).
*   **Если у тебя macOS или Linux:** Открой терминал и вставь туда эту магическую команду (она скачает и запустит установщик):
    ```bash
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
    ```

После установки, чтобы убедиться, что всё прошло успешно, закрой терминал, открой его заново и введи команду:
```bash
rustc --version
```
Если в ответ ты увидишь что-то вроде `rustc 1.75.0 (...)`, поздравляю! Инспектор готов к работе.

#### Первая программа

Давай напишем традиционную программу, которую пишет каждый программист при изучении нового языка — программу, которая просто печатает текст «Hello, world!» (Привет, мир!).

1. Создай на компьютере папку для своих экспериментов, например `rust_learning`.
2. Внутри этой папки создай обычный текстовый файл и назови его `main.rs`. Расширение `.rs` говорит о том, что внутри находится код на языке Rust (от слова **R**u**s**t).
3. Открой этот файл в любом блокноте (или в редакторе кода, если он у тебя есть) и напиши следующий код:

```rust
// Это наша первая программа. 
// Текст после двух косых черт - это комментарий. 
// Комьютер его игнорирует, он нужен только для нас, людей.

fn main() {
    println!("Hello, world!");
}
```

**Давай разберем каждое слово под микроскопом:**

*   `fn` — это сокращение от слова «function» (функция). Функция — это просто блок кода, который выполняет какую-то конкретную задачу. 
*   `main` — это имя функции. Но это не простое имя. Для языка Rust функция `main` (главная) — это точка входа. Когда ты запускаешь программу, компьютер всегда начинает искать функцию с именем `main` и выполняет команды, которые находятся внутри нее. Нет `main` — программа не знает, откуда стартовать.
*   `()` — круглые скобки. Здесь мы могли бы передать функции какие-то стартовые данные, но нашей функции `main` они не нужны, поэтому скобки пустые.
*   `{ ... }` — фигурные скобки. Это "стены" нашей функции. Все команды, которые находятся между открывающей `{` и закрывающей `}` скобкой, принадлежат функции `main`.
*   `println!` — это команда (инструкция) напечатать текст на экране и перейти на новую строку (print line). Обрати внимание на восклицательный знак `!`. В Rust он означает, что мы вызываем не просто функцию, а **макрос**. Мы разберем эту магию позже (в Главе 20), но пока просто запомни правило: если видишь восклицательный знак, это макрос.
*   `"Hello, world!"` — это сам текст, который мы хотим напечатать. Текст всегда берется в двойные кавычки.
*   `;` — точка с запятой. Это знак «стоп» для текущей команды. Он говорит компилятору: «Эта инструкция закончена, переходи к следующей». В Rust точка с запятой в конце действий обязательна.

**Как это запустить?**

Открой терминал в той папке, где лежит твой файл `main.rs`, и введи команду, которая вызовет компилятор:

```bash
rustc main.rs
```

Если ты не допустил опечаток, компилятор молча сделает свою работу (в мире программирования отсутствие новостей — это хорошие новости). В твоей папке появится новый файл — готовая программа (`main.exe` на Windows или просто `main` на Linux/Mac). 

Теперь запусти эту программу:
*   На Windows: `.\main.exe`
*   На Mac/Linux: `./main`

На экране появится заветная фраза:
`Hello, world!`
