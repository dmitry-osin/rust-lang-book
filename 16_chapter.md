### Глава 16. Взаимодействие с ОС (Ввод/Вывод и Файлы)

Когда программа обращается к внешнему миру (жесткому диску или клавиатуре), она просит помощи у Операционной Системы (Windows, macOS, Linux). Операционная система может отказать: файла нет, нет прав доступа, диск переполнен. Поэтому почти все функции из этой главы будут возвращать уже знакомый нам тип **`Result`**, который мы обязаны обработать!

#### 1. Ввод данных с клавиатуры

Чтобы прочитать то, что пользователь печатает в терминале, нам понадобится стандартный модуль ввода/вывода — `std::io`.

Логика работы такая:
1. Мы создаем пустую динамическую строку (`String`), которая будет служить "ведерком".
2. Мы просим операционную систему: "Пожалуйста, подожди, пока пользователь нажмет Enter, и высыпи всё, что он напечатал, в мое ведерко".

```rust
use std::io; // Подключаем модуль ввода/вывода

fn main() {
    println!("Пожалуйста, введите ваше имя:");

    // Создаем изменяемую пустую строку ("ведерко")
    let mut user_name = String::new();

    // io::stdin() открывает стандартный поток ввода (клавиатуру)
    // Метод read_line принимает ИЗМЕНЯЕМУЮ ССЫЛКУ на нашу строку, 
    // чтобы записать туда данные.
    // read_line возвращает Result, поэтому мы используем expect для обработки ошибки.
    io::stdin()
        .read_line(&mut user_name)
        .expect("Не удалось прочитать строку");

    // ВАЖНЫЙ МОМЕНТ: Метод trim()
    // Когда пользователь нажимает Enter, в строку записывается не только текст, 
    // но и невидимый символ переноса строки (\n). 
    // Метод trim() обрезает пробелы и переносы по краям текста.
    println!("Привет, {}! Добро пожаловать в Rust.", user_name.trim());
}
```

#### 2. Работа с файлами: Чтение и Запись

В Rust есть супер-короткие и удобные методы для работы с файлами, когда тебе нужно просто прочитать файл целиком или перезаписать его. Они находятся в модуле `std::fs` (File System).

Давай напишем программу, которая создает файл, записывает в него секретное сообщение, а потом читает его обратно.

```rust
use std::fs; // Модуль файловой системы

fn main() {
    let file_path = "secret_diary.txt";
    let message = "Сегодня я изучил модули и файлы в Rust!";

    // 1. ЗАПИСЬ
    // fs::write создает файл (или очищает его, если он уже есть) и записывает байты.
    // Если у нас нет прав на запись в эту папку, функция вернет Err.
    match fs::write(file_path, message) {
        Ok(_) => println!("Файл успешно сохранен!"),
        Err(e) => println!("Ой! Ошибка при сохранении: {}", e),
    }

    // 2. ЧТЕНИЕ
    // fs::read_to_string открывает файл и пытается прочитать его как UTF-8 текст.
    match fs::read_to_string(file_path) {
        Ok(content) => println!("Прочитано из файла:\n{}", content),
        Err(e) => println!("Не могу прочитать файл: {}", e),
    }
}
```

*А что если файл огромный (например, логи на 5 Гигабайт)?*
Функция `read_to_string` попытается загрузить все 5 ГБ в оперативную память (в `String`). Твой компьютер может зависнуть. Для больших файлов используют так называемое "буферизованное чтение" (построчное чтение). Мы открываем файл (`File::open`) и читаем его по одной строке, обрабатываем её и сразу удаляем из памяти.

#### 3. Работа с каталогами (Папками)

Программа часто должна уметь создавать папки для своих файлов или сканировать существующие папки (например, чтобы найти все картинки в директории). 

Для этого тоже используется `std::fs`. Давай создадим папку и посмотрим, что внутри неё.

```rust
use std::fs;
use std::path::Path; // Удобный модуль для работы с путями (слэшами)

fn main() {
    let folder_name = "my_rust_data";

    // 1. Создаем директорию
    // Возвращает ошибку, если папка уже существует, поэтому мы игнорируем ошибку 
    // с помощью let _ = ... (на практике лучше проверить, какая именно ошибка вернулась)
    let _ = fs::create_dir(folder_name); 
    
    // Создадим пустой файл внутри нашей новой папки, 
    // чтобы нам было на что посмотреть
    let file_path = format!("{}/test.txt", folder_name);
    let _ = fs::write(file_path, "Тестовые данные");

    // 2. Чтение содержимого директории
    println!("Содержимое папки '{}':", folder_name);
    
    // read_dir возвращает Итератор по файлам и папкам внутри указанной директории
    if let Ok(entries) = fs::read_dir(folder_name) {
        for entry in entries {
            if let Ok(item) = entry {
                // Достаем имя файла/папки
                let file_name = item.file_name();
                // Конвертируем в обычную строку (Lossy значит "заменить битые символы", 
                // так как в ОС имена файлов не всегда идеальный UTF-8 текст)
                println!("- {}", file_name.to_string_lossy());
            }
        }
    } else {
        println!("Не удалось открыть папку.");
    }
}
```

---

**Резюме:**
*   **`std::io::stdin().read_line()`** — способ получить текст от пользователя с клавиатуры (не забывай делать `.trim()`).
*   **`std::fs::write()`** и **`std::fs::read_to_string()`** — удобные способы сохранить текст в файл и прочитать его оттуда.
*   **`std::fs::create_dir()`** и **`std::fs::read_dir()`** позволяют управлять папками и сканировать их содержимое.
*   Поскольку работа с жестким диском и устройствами ввода — это непредсказуемый процесс, все эти функции возвращают **`Result`**. Операционная система всегда может отказать тебе в доступе.
