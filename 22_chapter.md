### Глава 22. FFI: Взаимодействие с нативным кодом (C/C++)

Иногда тебе нужно использовать старую надежную библиотеку на языке C или написать сверхбыструю вставку на ассемблере. Для этого существует **FFI (Foreign Function Interface)**.

#### 1. Вызов функций из C

Для этого мы используем блок `extern "C"`. Внутри него мы просто описываем, как выглядит функция в языке C.

```rust
// Подключаем стандартную библиотеку C (например, для вычисления квадратного корня)
#[link(name = "m")] // линковка с математической библиотекой
extern "C" {
    fn sqrt(input: f64) -> f64;
}

fn main() {
    // Любой вызов внешней функции — это потенциальная опасность (память не под контролем Rust).
    // Поэтому вызов ВСЕГДА должен быть обернут в unsafe.
    let result = unsafe { sqrt(25.0) };
    println!("Квадратный корень из C: {}", result);
}
```

#### 2. Совместная компиляция (скрипт build.rs)

Если у тебя есть файл `hello.c`, ты можешь попросить Cargo скомпилировать его прямо во время сборки Rust-проекта. Для этого создается файл `build.rs` в корне проекта. Это "скрипт сборки", который запускается перед компиляцией основного кода.

#### 3. Представление данных в памяти (`#[repr(C)]`)

Компьютер по-разному раскладывает структуры в памяти в Rust и в C. Если ты хочешь передать структуру из Rust в функцию на C, ты должен приказать Rust использовать "сишный" стандарт расположения данных:

```rust
#[repr(C)] // Теперь эта структура в памяти выглядит точно так же, как struct в языке C
struct Point {
    x: i32,
    y: i32,
}
```
