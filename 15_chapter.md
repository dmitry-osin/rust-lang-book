### Глава 15. Коллекции и Итераторы

В стандартной библиотеке Rust есть три главные коллекции: Вектор, Строка и Хэш-таблица. Разберем их по очереди.

#### 1. Вектор (`Vec<T>`): Динамический массив

Вектор — это длинная полка на складе. Он хранит элементы **одного типа**, расположенные в памяти строго друг за другом. Ты можешь добавлять новые элементы в конец, и полка будет автоматически "удлиняться".

**Создание и добавление:**
```rust
fn main() {
    // Способ 1: Создаем пустой вектор (нужно явно указать тип, так как он пуст)
    let mut names: Vec<String> = Vec::new();
    names.push(String::from("Дмитрий"));
    names.push(String::from("Алексей"));

    // Способ 2: Используем удобный макрос vec! (тип i32 выведется автоматически)
    let mut numbers = vec![1, 2, 3];
    numbers.push(4);
}
```

**Чтение элементов (Два способа):**
Достать значение из вектора можно либо напрямую, либо безопасно (через `Option`).

```rust
let v = vec![10, 20, 30, 40, 50];

// Способ 1: Прямой доступ (через индекс).
// ОПАСНО! Если ты напишешь &v[100], программа мгновенно запаникует (упадет).
let third: &i32 = &v[2]; 
println!("Третий элемент: {}", third);

// Способ 2: Метод .get() возвращает Option<&T>.
// БЕЗОПАСНО! Если элемента нет, он просто вернет None.
match v.get(100) {
    Some(value) => println!("Элемент найден: {}", value),
    None => println!("Элемента с таким индексом не существует."),
}
```

#### 2. Загадка строк: `String` против `&str`

Это боль номер один для всех новичков. Почему в Rust два типа строк? 

*   **`&str` (Строковый срез / String Slice):** Это просто *ссылка* на текст, который уже где-то лежит (например, запечен в самом коде программы: `let s: &str = "Привет";`). У тебя нет Владения, и ты не можешь изменить этот текст или добавить в него буквы. Он быстрый и фиксированный.
*   **`String`:** Это полноценная структура-владелец. Она хранит данные в Куче, может расти и меняться.

```rust
// Превращаем фиксированный текст (&str) в динамическую строку (String)
let mut s = String::from("foo");
// или так:
let mut s2 = "foo".to_string();

// Теперь мы можем её менять!
s.push_str("bar"); 
println!("{}", s); // Выведет "foobar"
```

**Почему в Rust нельзя достать букву по индексу: `s[0]`?**
В C++ или Java ты можешь написать `string[0]` и получить первую букву. Если ты попробуешь это в Rust, компилятор выдаст ошибку! 

Дело в том, что строки в Rust используют кодировку **UTF-8**. Это значит, что английская буква 'A' занимает 1 байт. Русская 'Д' занимает 2 байта. А эмодзи '🚀' занимает 4 байта!
Если Rust попытается просто взять "первый байт", он может отрезать половину русской буквы, и программа сломается (выдаст белиберду).

Если тебе нужно пройтись по строке посимвольно, используй метод `.chars()`:
```rust
for c in "Здравствуй, 🌍!".chars() {
    println!("{}", c); // Выведет каждый символ отдельно
}
```

#### 3. Хэш-таблицы (`HashMap<K, V>`): Словари

Векторы ищут по числовому индексу (0, 1, 2). А Хэш-таблицы ищут по **Ключу** (Key). Это как записная книжка: ключ — имя, значение — номер телефона.

В отличие от Вектора и Строк, `HashMap` нужно явно подключать из стандартной библиотеки.

```rust
use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();

    // Вставляем данные: Ключ - название команды (String), Значение - очки (i32)
    scores.insert(String::from("Синие"), 10);
    scores.insert(String::from("Красные"), 50);

    // Достаем значение по ключу. Возвращается Option, так как ключа может не быть.
    let team_name = String::from("Синие");
    let score = scores.get(&team_name); 

    // Изящное обновление: "Если ключа Желтые нет - вставь 50, а если есть - ничего не делай"
    scores.entry(String::from("Желтые")).or_insert(50);
}
```

#### 4. Итераторы: Магия функционального программирования

Циклы `for` — это хорошо. Но когда тебе нужно обработать огромный список данных, писать `for` с кучей `if` внутри становится грязно. В Rust есть **Итераторы**, которые позволяют делать сложные преобразования данных в одну красивую строчку.

Итератор — это паттерн, который выдает элементы один за другим.
В Rust итераторы ленивые. Это значит, что пока ты не попросишь у них результат, они ничего не делают.

Давай решим классическую задачу: у нас есть вектор чисел. Нам нужно:
1. Оставить только четные числа.
2. Возвести их в квадрат.
3. Сложить их все вместе.

**Как бы это выглядело с обычным циклом (Императивный подход):**
```rust
let v = vec![1, 2, 3, 4, 5, 6];
let mut sum = 0;

for x in v {
    if x % 2 == 0 {
        sum += x * x;
    }
}
println!("Сумма: {}", sum);
```

**А вот как это делают сеньоры с помощью Итераторов (Декларативный подход):**
```rust
let v = vec![1, 2, 3, 4, 5, 6];

// Внимание на эту красоту:
let sum: i32 = v.into_iter() // Превращаем вектор в итератор
    .filter(|x| x % 2 == 0)  // Оставляем только те, где остаток от деления на 2 равен 0 (замыкание!)
    .map(|x| x * x)          // Берем каждый элемент и умножаем сам на себя
    .sum();                  // Поглощаем итератор, складывая все элементы

println!("Сумма: {}", sum);
```
Эта цепочка читается как английский текст: *"Преврати в итератор -> отфильтруй -> преобразуй -> просуммируй"*. 
И что самое главное: благодаря умному компилятору Rust, этот красивый код работает **точно так же быстро**, как и "грязный" цикл `for`. Никаких просадок по производительности (Zero-cost abstraction)!

Ключевые методы итераторов, которые стоит знать:
*   `.map(|x| ...)` — изменяет каждый элемент.
*   `.filter(|x| ...)` — оставляет только элементы, подходящие под условие.
*   `.collect()` — собирает результаты работы итератора обратно в новую коллекцию (например, новый Вектор).
*   `.sum()` / `.count()` — подсчитывает сумму или количество элементов.

---

**Резюме:**
*   **`Vec<T>`** — когда нужен изменяемый список однотипных элементов.
*   **`String`** — динамическая строка в Куче. **`&str`** — быстрая ссылка на текст. Строки не поддерживают индексацию `[0]` из-за особенностей UTF-8.
*   **`HashMap<K, V>`** — словарь для поиска значений по ключу.
*   **Итераторы** — мощнейший инструмент для функциональной и сверхбыстрой обработки потоков данных (методы `map`, `filter`, `collect`).
